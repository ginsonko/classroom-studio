# 分层练习题

## 产出
1. `<主题>-练习.md`：学生卷（导播台排成 Word / PDF）。
2. `<主题>-答案.md`：答案和解析，给老师用。
3. `<主题>-题库.json`：按技能 question-json 的格式，每道题一条，**每题带出处**。
4. `<主题>-学生长图.md`：给学生手机看的题目版（导播台自动排成一张 750px 宽的长图 PNG，微信直接发）。

## 好成品的样子（下限）
样板：`.cs-kit/examples/practice-set/`（有的话先看）。以「超重与失重」为例：
- 基础 5 + 提高 3 + 拓展 2（老师另有要求以老师为准），**难度分布写在卷首**（例如「基础 5 题 · 提高 3 题 · 拓展 2 题，约 35 分钟」）。
- **每题标出处**：题号后面括注，例如「1.（2024 北京海淀高一上期中 第 7 题）」「6.（改编自 2023 北京西城高一期末 第 15 题）」「9.（原创）」。真题要能查到：题库里带网址或原卷文件。
- 题型搭配合理（选择、填空、计算、实验 / 说理都有），每个知识点至少一题，学生薄弱的点多一题；至少一题联系生活情境（电梯、过山车、航天员）。
- 解析写**关键步骤 + 易错点**（「误以为向上运动就是超重」），不是只给答案。
- 学生长图版：只放题目和作答提示，字大，一屏两三题，手机上不用放大就能看。

## 找真题（任务要真题，或老师说「从近几年的卷子里找」时）
- **找到一道就先写成品（第一轮必落盘）**：核实到第 1 道带出处的真题后，**立刻先把 `<主题>-练习.md`、`<主题>-答案.md`、`<主题>-题库.json` 建出来写盘**，之后每核实一道题就追加更新一次，绝不要等全部找齐或看完所有图片才开始写文件；原卷里没给参考答案时先自己算出解析或如实注「原卷未附答案，以下为自解」，不要为了找现成答案反复翻页耗尽预算。
- 按工作手册的「联网找资料」做：先老师给的来源，再各区教研网、教育局 / 考试院官网、学校公开试卷、公开真题汇编；要登录的站不硬爬，请老师登录或下载后拖进来。
- 原卷下载到「资料/来源」（web_fetch / browser_download 会自动存），题库里 `source.file` 指向它。
- 原卷原文用搜索工具打开（网页搜索、`web_fetch`、内置浏览器都行）；能下载就存进「资料/来源」，下载不了也没关系，`url` 写原卷网址（PDF 也行），导播台会自己下载原卷核对。
- **真题照录原文**：题干、数字、选项一个字不改才算「真题」（只允许把公式改成 LaTeX、把「如图」的条件写进题干）。「改编」只改数字或问法、原题主体句子保留；整题重写的不算改编，标「原创」（可以在解析里写「参考 2024 顺义期末第 11 题」）。导播台按题干相似度和数字核对，重写过的会被判「来源未核实」。
- 找不够就用原创补，**如实标「原创」**，收尾里说清各有几道。

## 练习.md 的格式
```markdown
<!-- cs:theme=主题色，见任务背景 -->
# 超重与失重 · 分层练习

基础 5 题 · 提高 3 题 · 拓展 2 题　　建议用时 35 分钟

[[表头 姓名|日期|用时|得分]]

## 一、基础巩固

1.（2024 北京海淀高一上期中 第 7 题）题干……

   A. ……　B. ……　C. ……　D. ……

2.（原创）计算题题干……

[[留空]]

## 二、能力提高
……
```
- 标题下 `[[表头 ……]]` 是学生填写栏，栏目用 `|` 隔开；不要自己写「姓名：____」。
- 填空用 `____`（四个下划线）；计算、解答题后面放 `[[留空]]` 给学生写过程。
- 需要图时先把条件写进题干；真要图就放进文件夹再引用（原卷截图、或写「素材需求.json」生成示意图），不要引用不存在的图片。

## 答案.md 的格式
每题：`**1.** 答案：……` 换行写「解析：」，关键步骤配公式，最后一句「易错：……」；末尾加「易错提醒」2～3 条，和一张「题号 | 知识点 | 难度 | 出处」的表。

## 学生长图.md 的格式
```markdown
# 超重与失重 · 练习（学生版）

> 做完拍照发给老师。建议用时 35 分钟。

## 一、基础巩固
1. 题干……
   A. ……　B. ……
```
只放题目，不放答案、出处括注和填写栏。

## 评分表（每条 0 / 1 / 2 分，≥ 12 分才交付）
| # | 项目 | 2 分的样子 |
|---|---|---|
| 1 | 科学性 | 每题条件完备、答案唯一、数值验算过，题库 verified 有依据 |
| 2 | 出处真实 | 每题都有出处；真题能在网址 / 原卷里找到原题；改编、原创如实标注 |
| 3 | 分层与难度 | 基础 / 提高 / 拓展梯度清楚，卷首写了难度分布和用时 |
| 4 | 覆盖与针对性 | 知识点全覆盖，薄弱点多练，有生活情境题 |
| 5 | 解析质量 | 关键步骤 + 易错点，学生看得懂 |
| 6 | 格式 | 表头、留空、编号、选项排版规范；三个文件题号一一对应 |
| 7 | 学生版 | 长图版字大、只放题目，手机上能直接看 |

## 自查步骤
1. 每道题写完立刻按 question-json 的「独立重做」验算。
2. 真题逐题对照原卷核一遍：题干、数字、选项和原卷一致；网址打开确实是这份卷子。
3. 四个文件通读：编号连续、题目一致、出处一致；题库 JSON 合法。
4. 对照评分表打分，低于 2 分的项先改。

## 常见翻车点
- 把原创题、改了数字的题标成真题（导播台会核对，对不上会标「来源未核实」并打回来）。
- 编一个看起来像真的网址或卷名。
- 选择题有两个对的选项；计算题数值算不出整数又没说保留几位。
- 题库 JSON 里反斜杠只写一个，导入失败。
- 解析只写答案，不写为什么、学生容易错在哪。

## 收尾
回复：每道题考查的知识点和难度（一行一题）；「找到真题 N 道、改编 J 道、原创 K 道」；没找到的、需要老师登录或下载的来源。
