# 练习题

## 产出
1. `<主题>-练习.md`：只放题目，给学生用。
2. `<主题>-答案.md`：答案和解析，给老师用。
3. `<主题>-题库.json`：按技能 question-json 的格式，每道题一条。

## 流程
1. 读「任务背景.md」：年级、教材、薄弱点、本学科题型、出题和答案的写法要求。
2. 先在心里定好知识点清单（3～6 个），每个知识点至少一题；学生薄弱的点多出一题。
3. 默认结构（老师另有要求时以老师为准）：基础 5 题（difficulty 1～2）+ 提高 3 题（3～4）+ 拓展 2 题（4～5）。题型搭配要合理，不要全是一种题型。
4. 每道题写完立刻按 question-json 里的「独立重做」验算，不通过就改，不要留到最后。
5. 三个文件一起写好，再整体通读一遍：编号连续、两份 Markdown 和 JSON 里的题一一对应。

## 练习.md 的格式
```markdown
<!-- cs:theme=主题色，见任务背景 -->
# 斜面上的受力分析 · 练习

[[表头 姓名|日期|用时|得分]]

## 一、基础巩固

1. 题干……

   A. ……　B. ……　C. ……　D. ……

2. 计算题题干……

[[留空]]

## 二、能力提高
……
```
- 标题下一行 `[[表头 ……]]` 是学生填写栏（导出时画成带横线的格子），栏目用 `|` 隔开；不要自己写「姓名：____」。
- 填空题的空用 `____`（四个下划线）表示，导出时会画成横线。
- 计算、解答、证明题后面放一行 `[[留空]]` 给学生写过程。
- 需要图时，用文字把图描述完整（例如「如图：质量为 m 的物块静止在倾角 θ 的斜面上」改成把条件写进题干），不要引用不存在的图片。
- 选择题选项较短时可以写在同一行，用全角空格隔开。

## 答案.md 的格式
每题：`**1.** 答案：……` 换行后写「解析：」，关键步骤配公式；最后加一节「易错提醒」列 2～3 条。

## 收尾
回复里列出每道题考查的知识点和难度，一行一题。
