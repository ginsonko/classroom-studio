# 课堂讲义

## 产出
1. `<主题>-讲义.md`：导播台排成 Word 和 PDF（A4），学生上课时边听边记、课后复习用。
2. 需要发手机时另写 `<主题>-讲义长图.md`（自动排成长图 PNG）。

## 好成品的样子（下限）
样板：`.cs-kit/examples/lesson-notes/`（有的话先看）。两页 A4，打印出来就能发：
- 开头一张**知识结构图**（```结构图，见下），一眼看清这节课讲什么。
- **公式卡**：公式 | 含义 | 适用条件，一张表；关键词加粗。
- **方法步骤** 4～6 步，**易错点** 3～5 条（错误想法 → 正确理解），学生的薄弱点重点写。
- **两道例题**：一道基础一道中档，分步解析、关键公式单独一行；数值自己设计并验算。
- **留白笔记区**：例题和课堂小练后面留 `[[留空]]`，学生能在纸上写。
- 文科：「公式卡」换成「核心概念 / 关键句式 / 答题模板」，保留表格形式。

### 结构图写法
用 ```结构图 开头、``` 结尾的代码块，里面每行一个节点，**缩进两个空格表示下一层**，第一行是中心主题，最多 3 层、每个节点不超过 16 个字。导出时画成树状图（Word 里是图片）。

## 评分表（每条 0 / 1 / 2 分，≥ 11 分才交付）
| # | 项目 | 2 分的样子 |
|---|---|---|
| 1 | 科学性 | 概念、公式、条件、例题数值全对 |
| 2 | 结构清楚 | 有知识结构图，一眼看清本课框架 |
| 3 | 公式卡 | 公式、含义、适用条件齐全，关键词加粗 |
| 4 | 易错点 | 针对学生薄弱点，写成「错误想法 → 正确理解」 |
| 5 | 例题 | 一基础一中档，分步解析，验算过 |
| 6 | 打印友好 | 两页 A4 以内，有留白笔记区，不复述教材大段原文 |

## 自查步骤
1. 估算长度：正文约 1200～1800 字、两道例题、一张结构图、一张表，基本就是两页。
2. 结构图代码块闭合、缩进对；公式写法对（导播台会检查公式能不能渲染）。
3. 对照评分表打分，低于 2 分的项先改。

## 常见翻车点
- 写成教材原文的摘抄，四五页长。
- 结构图写成普通列表或缩进乱了，层级画错。
- 没有留白，学生没地方记笔记。

## 收尾
回复：讲义覆盖了哪几个要点、例题考什么、大约几页。
