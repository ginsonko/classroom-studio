# 题库文件（<主题>-题库.json）

导播台会读这个文件，把题目放进老师的题库，之后组卷、布置作业、错题追踪都用它。所以它必须是**合法 JSON**（UTF-8，双引号，不要注释，不要尾逗号）。

```json
{
  "version": 1,
  "topic": "超重与失重",
  "questions": [
    {
      "stem": "题干。公式用 $...$；选择题把选项写进题干，每个选项单独一行：\nA. ...\nB. ...",
      "answer": "最终答案，简短，按「任务背景.md」里的答案写法",
      "analysis": "解析：关键步骤，3～8 行；最后一句写易错点",
      "qtype": "选择",
      "difficulty": 2,
      "verified": true,
      "source": { "kind": "真题", "title": "2024 北京海淀区高一上学期期中物理", "no": "第 7 题", "year": "2024", "region": "北京海淀", "url": "https://…", "file": "资料/来源/2024海淀高一期中.pdf" }
    },
    { "stem": "……", "answer": "……", "analysis": "……", "qtype": "计算", "difficulty": 3, "verified": true, "source": { "kind": "原创" } }
  ]
}
```

## 字段要求
- `qtype` 必须是「任务背景.md」里列出的本学科题型之一，拿不准就写「其他」。
- `difficulty`：1 基础、2 巩固、3 中档、4 较难、5 压轴，整数。
- `verified`：你按下面的方法独立重做过且答案一致才写 true；否则写 false，并在 `analysis` 末尾写一句「待老师核对：原因」。
- **`source` 每题必填**：
  - `kind`：`真题`（原题照录，数字条件都没改）/ `改编`（改了数字、条件或问法，title 写「改编自 …」）/ `原创`（自己出的，只写 kind 即可）。
  - 真题、改编要写 `title`（卷名）、`no`（题号）、`year`、`region`，以及 `url`（能打开、里面有这道题的网页）或 `file`（原卷存在当前文件夹里的位置，如老师拖进来的「附件/…」或下载到的「资料/来源/…」）。两个都有更好。
  - 导播台交付前会自己打开网址 / 原文，看里面是不是真有这道题（题干相似、数字一致）：对不上的标「来源未核实」，不能叫真题。**不要编网址、编卷名**；找不到出处就老实标「原创」。
- JSON 字符串里的反斜杠要写两个：`$\\frac{1}{2}mv^2$`、`\\ce{H2O}`。这是最容易出错的地方。
- 题目、答案和 Markdown 成品里的内容保持一致（同一道题不要两处数值不同，出处也一致）。联网找题时**核实到第 1 道就先把题库 JSON 和 Markdown 成品写盘**，之后逐题增量更新，不要等全部找完再一次性写。

## 独立重做（verified 的依据）
1. 只看题干，不看自己写的答案，重新完整解一遍。
2. 数值题检查单位、有效数字、量级是否合理；选择题确认只有一个正确选项（多选题注明「多选」）。
3. 结果和答案不一致：先改题或改答案，再重做，直到一致。

## 自查
- 写完后再读一遍这个 JSON，确认括号、引号、逗号都配对，反斜杠写了两个。
- 每题都有 `source`；真题 / 改编的网址或原文文件真实存在（原文文件就在当前文件夹里）。
- 题数、题号顺序和 Markdown 成品一一对应。
