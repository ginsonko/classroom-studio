# 题库文件（<主题>-题库.json）

导播台会读这个文件，把题目放进老师的题库，之后组作业、错题追踪都用它。所以它必须是**合法 JSON**（UTF-8，双引号，不要注释，不要尾逗号）。

```json
{
  "version": 1,
  "topic": "斜面上的受力分析",
  "questions": [
    {
      "stem": "题干。公式用 $...$；选择题把选项写进题干，每个选项单独一行：\nA. ...\nB. ...",
      "answer": "最终答案，简短，按「任务背景.md」里的答案写法",
      "analysis": "解析：关键步骤，3～8 行",
      "qtype": "计算",
      "difficulty": 3,
      "verified": true
    }
  ]
}
```

字段要求
- `qtype` 必须是「任务背景.md」里列出的本学科题型之一，拿不准就写「其他」。
- `difficulty`：1 基础、2 巩固、3 中档、4 较难、5 压轴，整数。
- `verified`：你按下面的方法独立重做过且答案一致才写 true；否则写 false，并在 `analysis` 末尾写一句「待老师核对：原因」。
- JSON 字符串里的反斜杠要写两个：`$\\frac{1}{2}mv^2$`、`\\ce{H2O}`。这是最容易出错的地方。
- 题目、答案和 Markdown 成品里的内容保持一致（同一道题不要两处数值不同）。

独立重做（verified 的依据）
1. 只看题干，不看自己写的答案，重新完整解一遍。
2. 数值题检查单位、有效数字、量级是否合理；选择题确认只有一个正确选项（多选题注明「多选」）。
3. 结果和答案不一致：先改题或改答案，再重做，直到一致。

写完后再读一遍这个 JSON，确认括号、引号、逗号都配对。
