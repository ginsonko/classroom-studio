# 单文件 HTML 互动课件

## 产出
`<主题>.html`：一个文件，CSS 和 JS 都写在里面，导播台直接在课堂上打开共享给学生。

## 硬性要求
- 完全离线：不引用任何网络资源（没有 CDN、外链字体、在线图片、import 网址）。写完后在文件里搜索 `http`，除注释外不应出现。
- 不用任何框架，原生 HTML / CSS / JavaScript；不依赖 localStorage（导播台里可能不可用）。
- 16:9 画面，铺满窗口并随窗口缩放；字号大（正文不小于 24px 等效），对比度高，留白充足；中文字体用系统字体栈。
- 按页组织：键盘 ← → 和屏幕上的上一页 / 下一页按钮翻页，右下角显示「当前页 / 总页数」。每页一个知识点。
- 公式：没有网络就没有 KaTeX，所以用 HTML 上下标（`v<sub>0</sub>`、`x<sup>2</sup>`）和 Unicode 符号（θ、Δ、√、×、·）写清楚；复杂公式用 canvas 画或分步写。

## 动画页（至少一页，最多三页）
- 用 `<canvas>` + `requestAnimationFrame` 做真正会动的演示：物理做仿真（按真实公式逐帧积分）、数学画函数图像并随参数变化、化学做粒子 / 反应示意，其他学科做时间轴、地图标注、结构拆解等。
- 每个动画配 1～3 个滑块调参数，滑块旁实时显示数值和单位；有「播放 / 暂停」和「重置」按钮。
- 数值必须符合学科规律（常数取值按「任务背景.md」里的约定，例如 g 取 10 m/s²），画面上的量和读数一致；参数到极端值时不能崩（除零、越界要处理）。
- 画面里标注关键量（箭头、刻度、图例），坐标轴有单位。

## 随堂小测（最后两页）
- 倒数第二页：3 道题（选择题可点选，点选后显示对错和一句解释）。
- 最后一页：标题写「答案」，列出 3 道题的答案和简要解析。

## 流程
1. 读「任务背景.md」，定 6～10 页的结构（标题页 → 引入 → 知识点 → 动画 → 例题 → 小测 → 答案）。
2. 一次写完整个 HTML；脚本放在 `</body>` 前。
3. 自查：搜索 `http`；检查每个滑块都有 `input` 事件处理；翻页到最后一页不会越界；没有未定义的变量（通读一遍脚本）。

## 收尾
回复：几页、动画演示的是什么、可调哪些参数。
