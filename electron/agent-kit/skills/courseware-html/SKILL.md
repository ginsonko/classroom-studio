# 单文件 HTML 互动课件

## 产出
`<主题>.html`：一个文件，离线能打开（微信、手机浏览器、导播台课堂共享都能用）。写的时候引用 `.cs-kit/` 的设计包，交付前打包成单文件（导播台每轮结束也会自动打包，源文件留在 `.cs-src/`）。

## 好成品的样子（下限）
样板：`.cs-kit/示例骨架.html`（超重与失重：手画 a–t 图驱动电梯、受力箭头随加速度变化、KaTeX 公式分步出现、点选题当场判对错）；`.cs-kit/examples/courseware-html/` 里有完整样板时先打开看看水准。
- **一页一个点**，8～10 页：封面 → 情境引入（生活现象 / 问题）→ 概念与规律（公式分步出现）→ 仿真页（能拖参数、能播放）→ 归纳对比 → 例题分步 → 随堂小测（点选、当场出解析）→ 小结（结构图）。
- **至少一页是真仿真**：按真实公式逐帧积分（`CS.sim`），不是播放写死的动画；拖滑块或在图上画，画面、读数、受力箭头一起变；数值和单位跟学科规律一致（g 按任务背景的约定）。
- **公式漂亮**：一律 KaTeX（`$…$`），推导用 `.cs-step` 一步步出现。
- **看得清**：正文 ≥ 24px，页标题 40px 左右，颜色对比度高，投影仪上也看得清；每页留白，字不挤出页面。
- **学生自己能玩**：手机竖屏自动变长页，按钮、滑块手指好点；点选题点了马上给对错和一句解析。
- 风格：默认在 `clean`（清爽白）、`dark`（深色课堂，适合投屏）、`hand`（手绘风，适合初中和低年级）里挑一个适合学科和学段的；老师指定了风格、配色、版式、模板就按老师的。

## 硬性要求
- 完全离线：不引用任何网络资源（CDN、外链字体、在线图片）。图片放进文件夹（配图可以写「素材需求.json」让导播台生成），打包时会内嵌。
- 不用框架和构建工具，原生 HTML / CSS / JS + 设计包；不依赖 localStorage。
- 横屏 16:9 等比缩放（设计包已处理），手机竖屏自动长页；自己写的多栏布局用 `.cs-cols`，不要写死固定像素宽度的 grid。
- 参数到极端值不崩：除零、越界、负数开方要处理；动画切到别的页时要停。
- 最后两页：随堂小测（3 道点选题，`.cs-quiz`）、答案与解析（老师上课可以跳过）。

## 自查步骤
1. 写完先打包：Windows `.\.cs-kit\pack.cmd <主题>.html`，mac `sh .cs-kit/pack.sh <主题>.html`。
2. 有 `page_check` 工具时：横屏（1280×800）逐页截图看一遍；仿真页用 `steps` 拖滑块 / 点播放再截一张；手机（390×844、`full_page`）截一张长图。看：字有没有溢出、公式渲染了没有、动画动没动、控制台有没有报错。
3. 没有截图工具时，至少通读脚本：每个滑块都有 `onInput`，所有 canvas 都用 `CS.sim` 画，没有未定义的变量。
4. 对照评分表打分，低于 2 分的项先改。
5. 改已经打包过的课件：改 `.cs-src/<主题>.html`，再打包。

## 常见翻车点
- canvas 在没显示的页上直接画 → 翻过去是空白（改用 `CS.sim` 的 draw）。
- 仿真用写死的关键帧或 CSS 动画冒充，参数一拖就对不上。
- 公式用上下标和 Unicode 拼，或者 `$` 写在 canvas 里（canvas 里用 `CS.label`）。
- HTML 里的公式写 `<` `>` 会被当成标签截断：用 `\lt` `\gt`（或 `&lt;` `&gt;`）。
- 引用了 CDN 的 KaTeX、字体、图片，学生离线打开一片空白。
- 一页塞满大段文字；小测选项长，挤成两列看不清（长选项用 `class="cs-opts one-col"`）。
- 改了打包后的大文件而不是 `.cs-src` 里的源文件，下次打包又被覆盖。

## 收尾
回复：几页、仿真演示的是什么、可以调哪些参数、用的哪种风格、自检结果。
