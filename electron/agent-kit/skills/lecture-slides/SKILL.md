# 讲课 PPT

## 产出
`<主题>-课件.md`，导播台自动排成 **PPTX（文字能直接在 PowerPoint / WPS 里改，单击分步出现）** 和 PDF。需要情境图时另写「素材需求.json」，导播台会画好放进「配图/」。

## 好成品的样子（下限）
样板：`.cs-kit/examples/lecture-slides/`（有的话先看）。以「超重与失重」为例，14 页左右，**6 种版式都用上**：
封面 → 情境图（电梯里的体重秤，AI 配图 + 一个问题）→ 学习目标 → 概念（公式分步）→ 对比（超重 vs 失重）→ 图解（受力分析，左图右要点逐条出现）→ 例题分步（单击一步出一步）→ 易错点 → 随堂练习 → 总结卡 → 答案页。
- 有设计感：每页一个重点，大字、留白；配 2～3 张情境图；版式有变化，不是一路列表到底。
- 上课能一步步讲：推导、例题、要点用「分步」，老师单击一下出一步。
- 公式清楚：LaTeX 写，导出成高清图；要点句里的公式尽量单独成行或放句末（含公式的那一句会整体变成图片，不能直接改字）。

## 写法（排版器按这些规则排，务必遵守）
- 第一行主题色注释 `<!-- cs:theme=… -->`（见任务背景）；老师指定了颜色可以再加 `<!-- 主题色 #1f7a8c -->`。
- 每页之间单独一行 `---`；每页 `## 标题` 开头；第一页是封面（`# 标题` + 一行副标题）。
- **版式**：在页标题前面写一行注释，不写就按标题自动选：
  | 写法 | 用途 | 内容怎么写 |
  |---|---|---|
  | `<!-- 版式：封面 -->` | 第一页 | `# 标题` + 副标题一行，可加一张图 |
  | `<!-- 版式：情境 -->` | 引入、生活现象 | 一张图（`![说明](配图/x.png)`）+ 一个问题（`> …`）+ 1～2 行说明 |
  | `<!-- 版式：对比 -->` | 两个概念对照、易错对比 | `### 左边标题` 下面写要点，`### 右边标题` 下面写要点 |
  | `<!-- 版式：图解 -->` | 受力分析、实验装置、结构示意 | 一张图 + 3～5 条要点（`- …`），要点自动带 ①②③ |
  | `<!-- 版式：例题 -->` | 例题分步 | 题目写成 `> …`，解答每一步一条 `- …`，单击一步出一步 |
  | `<!-- 版式：总结 -->` | 小结 | 每条 `- **关键词**：一句话`，排成卡片 |
  标题里有「例题」「小结 / 总结」时自动用对应版式；其余页是普通版式（标题 + 要点）。
- **单击分步**：在页里写一行 `<!-- 分步 -->`，这一页的要点一条一条出现（例题版式默认就分步）。
- **插图**：`![电梯启动时人站在秤上](配图/电梯.png)` 引用文件夹里真实存在的图；还没有图就写 `[[插图 电梯启动时人站在秤上]]` 占位（PPT 里是虚线框，老师可以换成自己的图）。要 AI 画就写进「素材需求.json」：`[{"file": "配图/电梯.png", "prompt": "明亮的电梯里，一个高中生站在体重秤上，秤的示数清楚可见，扁平插画风格，无文字", "size": "1536x1024"}]`，最多 3 张。
- 每页正文不超过 6 行、一行不超过约 28 个汉字；独立公式 `$$…$$` 一页最多 3 个；表格最多 5 行 4 列。
- 最后一页是答案页：标题写「答案」，放随堂练习答案（上课时老师会跳过）。

## 评分表（每条 0 / 1 / 2 分，≥ 12 分才交付）
| # | 项目 | 2 分的样子 |
|---|---|---|
| 1 | 科学性 | 概念、公式、例题数值全对，验算过 |
| 2 | 版式与设计 | 6 种版式按内容用上，页页有重点、不拥挤，有 2～3 张情境图或插图位 |
| 3 | 讲课节奏 | 从现象到规律到应用，推导和例题用分步，老师能一步步讲 |
| 4 | 公式 | LaTeX 写法正确，公式单独成行、清楚 |
| 5 | 例题与练习 | 例题分步解答完整，随堂练习 2～3 题紧扣易错点，有答案页 |
| 6 | 可编辑 | 要点文字尽量是纯文字（公式单独成行），老师能直接改 |
| 7 | 贴合学生 | 例子、难度贴合任务背景 |

## 自查步骤
1. 通读：页数、每页行数、版式注释和内容写法是否对应（对比页有两个 `###`、例题页有 `>` 题目）。
2. 引用的图片都真实存在，或写成 `[[插图 …]]`、或列进素材需求.json。
3. 例题和练习的数值自己验算。
4. 对照评分表打分，低于 2 分的项先改。导播台每轮结束会检查公式能不能渲染、图片在不在。

## 常见翻车点
- 一页塞 10 行字；整套都是「标题 + 列表」，没有版式变化。
- 引用不存在的图片路径（会被自检打回）。
- 要点句子中间夹公式，导致整句变成图片改不了。
- 对比页只写了一个 `###`，排出来只有一栏。

## 收尾
回复：共几页、用了哪几种版式、哪几页分步、配了哪些图、哪一页最需要老师现场展开讲。
