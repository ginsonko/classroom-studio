# 课件设计包 cs-deck（任务文件夹里的 `.cs-kit/`）

做 HTML 成品（互动课件、网页版讲义 / 练习、长图页面）时用这套现成的样式和脚本，**不用从零写翻页、滑块、公式**。
写的时候引用 `.cs-kit/` 里的文件；交付前打包成单文件（导播台每轮结束也会自动打包），微信里点开就能用、不需要联网。

> 老师指定了自己的风格、模板或资料时，以老师的为准：这套组件可以只用一部分，也可以全部不用；但「单文件、离线能开、公式清楚」这三条不变。

## 1. 骨架

```html
<!doctype html>
<html lang="zh-CN"><head>
<meta charset="utf-8"><meta name="viewport" content="width=device-width,initial-scale=1">
<title>超重与失重</title>
<link rel="stylesheet" href=".cs-kit/vendor/katex.min.css">
<link rel="stylesheet" href=".cs-kit/cs-deck.css">
<style>/* 本课自己的样式 */</style>
</head>
<body data-style="clean">           <!-- clean 清爽白 / dark 深色课堂 / hand 手绘风；换主题色：style="--accent:#12a08f" -->
<main class="cs-deck">
  <section class="cs-page cs-cover"><h1>标题</h1><p class="cs-sub">副标题</p><div class="cs-meta"><span>高一物理</span><span>人教版 必修一</span></div></section>
  <section class="cs-page"><h2>页标题</h2> …内容… </section>
</main>
<script src=".cs-kit/vendor/katex.min.js"></script>
<script src=".cs-kit/vendor/auto-render.min.js"></script>
<!-- 化学方程式 \ce{…} 再加：<script src=".cs-kit/vendor/mhchem.min.js"></script> -->
<script src=".cs-kit/cs-deck.js"></script>
<script>CS.ready(function () { /* 动画、仿真写在这里 */ });</script>
</body></html>
```

- 每个 `<section class="cs-page">` 是一页，按 1280×720 设计（正文 26px、页标题 42px），横屏自动等比缩放铺满；**手机竖屏自动变成上下滑动的长页**（分步内容全部展开、多栏变单栏）。
- 翻页：键盘 ← →、空格、PageUp/PageDown，右下角按钮，触屏左右滑；地址栏 `#p3` 直接打开第 3 页。
- 完整可运行的例子：`.cs-kit/示例骨架.html`（超重与失重，含受力图、手画 a–t 图驱动的电梯仿真、点选题、结构图）。先看它再写。

## 2. 公式（KaTeX，字体已内嵌）
- 正文里直接写 `$F_N = m(g+a)$`、`$$x = v_0 t + \tfrac12 at^2$$`，页面加载时自动渲染。
- 独立公式放进 `<div class="cs-formula">$$…$$</div>`，会有框和阴影。
- 脚本里动态更新的读数：`CS.tex(el, 'F_N = ' + CS.fmt(N, 0) + '\\,\\mathrm{N}')`。
- 画布里写物理量用 `CS.label(ctx, 'F_N', x, y)`（支持 `_下标`、`^上标`、`_{多个字}`），不要在 canvas 里写 `$…$`。
- 不想被当成公式的 `$`（比如价格）写 `\$`，或放进 `class="no-tex"` 的元素里。

## 3. 排版组件（CSS 类）
| 类名 | 用途 |
|---|---|
| `.cs-cols` | 两栏；`style="--cols: 1.4fr 1fr"` 改比例；`.wide-left` / `.wide-right` |
| `.cs-grid-3` | 三栏卡片 |
| `.cs-card` | 白底卡片 |
| `.cs-key` | 重点框（左侧色条） |
| `.cs-note` / `.cs-warn` | 提示 / 易错（自动加「易错」标签） |
| `.cs-formula` | 独立公式框 |
| `.cs-list` | 要点列表（菱形项目符号） |
| `.cs-table` | 表格 |
| `.cs-figure` + `figcaption` | 插图（`<img src="配图/电梯.png">` 打包时会内嵌） |
| `.cs-tag` `.cs-big` `.cs-muted` | 标签、大字、浅色字 |
| `.cs-timeline` | 竖向时间轴：`<ol class="cs-timeline"><li data-time="0–5′"><b>回顾</b> …</li></ol>` |
| `.cs-timebar` | 比例时间条：`<div class="cs-timebar"><span data-min="5">回顾</span><span data-min="15">新授</span></div>`，宽度按分钟自动分 |
| `.cs-tree` | 知识结构图：嵌套 `<ul class="cs-tree"><li><b>超重与失重</b><ul><li><span>超重</span></li>…</ul></li></ul>` |

自己写多栏时用 `.cs-cols`，**不要写死 `grid-template-columns: 360px 1fr` 这种固定宽度的 grid**（手机竖屏会被挤出屏幕）。

## 4. 分步出现（像 PPT 的单击出现）
给元素加 `class="cs-step"`，按「下一步」时按文档顺序一个个出现，全部出现后再翻页；`data-step="2"` 可以让几个元素同时出现。
例题分步解答、推导过程、对比表逐行出现都用它。

## 5. 互动控件（JS）
```js
CS.ready(function () {
  var ctl = CS.$('#ctl');                       // 放控件的容器，建议 <div class="cs-controls" id="ctl"></div>
  var a = CS.slider(ctl, { label: '加速度 $a$', min: -5, max: 5, step: 0.5, value: 2, unit: 'm/s²', digits: 1, onInput: function (v) { sim.redraw(); } });
  a.value;                                      // 当前值
  CS.button(ctl, '换一组数据', function () { … }, 'ghost');

  var sim = CS.sim({
    canvas: CS.$('#cv'), controls: ctl,         // 自动加「播放 / 暂停」「重置」
    init: function (s) { s.t = 0; s.v = 0; s.y = 0; },
    step: function (s, dt) { s.v += a.value * dt; s.y += s.v * dt; s.t += dt; },   // dt 秒，按真实公式积分
    until: function (s) { return s.t >= 10; },
    draw: function (ctx, s, w, h) { … },        // w、h 是画布显示尺寸（CSS 像素）
  });
});
```
- **所有 canvas 图（包括静态示意图）都用 `CS.sim` 画**（不给 step 就是静态图）：翻到那一页、窗口缩放、手机竖屏时会自动按新尺寸重画。直接在 `CS.ready` 里画一次的 canvas，在没显示的页上会画成 10×10 的空图。
- `CS.fmt(v, 2)`：数字显示（去掉多余的 0，负号用 −）。`CS.clamp(v, a, b)`。`CS.color('--accent')` 取当前风格的颜色。

### 画图工具（canvas 2D）
```js
CS.arrow(ctx, x1, y1, x2, y2, { color, width: 4, label: 'v_0' });
CS.force(ctx, { x, y, w: 80, h: 80, label: '木块', scale: 0.2,          // 受力图：箭头长 = value × scale 像素
  forces: [{ name: 'F_N', value: 600, angle: 90, from: 'top' }, { name: 'mg', value: 500, angle: -90, from: 'bottom' }] });
var g = CS.plot(canvasApi, { x: [0, 10], y: [-5, 5], xLabel: 't/s', yLabel: 'v/(m·s^{-1})', xStep: 1, yStep: 1 });
g.axes(); g.fn(function (t) { return 2 * t - 5; }); g.line([[0, 0], [2, 4]], { dash: [6, 6] }); g.dot(2, 4, { label: 'P' });
var curve = CS.drawable(canvasApi, g, { n: 100, snap: 0.5, init: function (t) { return 0; }, onChange: function () { … } });  // 学生 / 老师按住拖动画曲线
curve.at(3.2);  curve.draw();
```
`canvasApi` 是 `CS.canvas('#id')` 的返回值，或 `CS.sim(...)` 返回值的 `.canvas`。

## 6. 点选题（点了马上判对错、出解析）
```html
<div class="cs-quiz" data-answer="C">            <!-- 多选写 data-answer="AC"，会出「提交」按钮 -->
  <p class="cs-q">1. 电梯减速上升时，人处于</p>
  <ol class="cs-opts"><li>超重状态</li><li>平衡状态</li><li>失重状态</li><li>完全失重状态</li></ol>   <!-- 选项字母自动加；长选项加 class="cs-opts one-col" -->
  <p class="cs-explain">减速上升，加速度向下，$F_N = m(g-a) < mg$。</p>
  <!-- 想让学生能重做：<button class="cs-btn ghost cs-retry">再做一次</button> -->
</div>
<span class="cs-score"></span>                    <!-- 自动显示「答对 2 / 3 题」 -->
```

## 7. 打包成单文件
- 导播台每轮结束会自动把新改过的 HTML 打包：引用的 `.cs-kit/…`、本地图片、字体全部内嵌，**源文件另存到 `.cs-src/同名.html`**。
- 自己打包（自查截图前想看最终效果）：Windows `.\.cs-kit\pack.cmd 超重与失重.html`；mac `sh .cs-kit/pack.sh 超重与失重.html`。
- **以后要改已经打包过的课件，改 `.cs-src/` 里那份**，再打包；不要去改打包后的大文件。
- 单文件大约 0.7 MB（大部分是公式字体）；配图尽量用 PNG/JPG、单张不超过 1 MB。

## 8. 自查（交付前必须做）
- 导播台每轮结束会在后台打开成品跑 `CS.selfTest()`：逐页显示、点遍按钮、拖遍滑块（最小 → 最大 → 原值）、点选题各点一次，收集脚本报错、公式错误、内容溢出页面、外部网络引用，横屏 1280×720 和手机竖屏各跑一遍。有问题会把清单发回给你修。
- 有截图工具时，自己再逐页截图看一遍：字有没有挤出页面、公式渲染了没有（看到 `$` 原样显示就是没渲染）、动画动没动、颜色在投影上看不看得清。
