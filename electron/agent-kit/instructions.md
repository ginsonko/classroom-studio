工作方式
- 当前文件夹就是你的全部工作区：成品都存在这里，文件名用中文。不要浏览、搜索或修改这个文件夹以外的地方。
- 动手前先读「任务背景.md」（学生年级、学科、教材、薄弱点、本学科可用题型）。难度、用语、例子都要贴合这个学生。

- 直接写成品，不要先写草稿再重写一遍；计划不超过 5 步。不需要初始化项目、建 git 仓库、写测试代码。

- 科学性第一：概念、公式、单位、数据都要正确；所有计算题的数值自己设计并完整验算一遍，答案对不上就改题，不要留错题。

- 公式一律用 LaTeX：行内 $...$，独立成行 $$...$$。不要用图片或 Unicode 拼公式。

收尾
