# 样板：超重与失重 ·「电梯体重秤」导播台插件

- **主题**：高一物理「超重与失重」（人教版必修一，$g = 10\,\mathrm{m/s^2}$）
- **插件 ID 与协议**：`elevator-scale`（`cs-plugin/1`）
- **界面与架构**：
  - `index.html`（教师端浮动控制面板，支持导播台 `console` 与教师浮层 `dock`）：引用 `/__cs/ui.css` 与 `--cs-*` 皮肤变量，深浅皮肤自适应；提供「上行/下行」切换、「启动 / 匀速 / 制动 / 自由落体」四阶段一键预设、加速度 $a$ 与质量 $m$ 连续滑块、电梯受力迷你预监、「投到学生画面」及「读数写黑板」按钮。
  - `screen.html`（学生画面全屏互动大屏）：三栏高清物理实验台（左侧镜头跟随电梯井道与弹簧秤形变动画、中间双针弹簧台秤表盘与 $F_N=m(g+a)$ 实时算式核算、右侧隔离体受力矢量图与 $F_N(t)$ 实时示波曲线），通过 `cs.storage` 与教师端毫秒级同步。
  - `icon.svg`：64×64 矢量插件图标。
- **权限最小化**：仅申请实际用到的 `present`（投屏学生画面）与 `board`（读数写黑板），`network: []` 完全离线运行。
