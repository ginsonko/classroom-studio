# 样板：超重与失重 · 自定义任务三件套（custom）

- **主题**：围绕高一物理「超重与失重 / 牛顿运动定律」（人教版 2019 必修第一册，$g = 10\,\mathrm{m/s^2}$）展示老师在「自定义」模式下最常做的三类跨形态创意成品。
- **三份真实成品与源文件对应关系**：
  1. **学情诊断信息长图**
     - 排版源文件：`月考错题归因与提分路线分析长图.html`
     - 离线成品图：`_showcase/月考错题归因与提分路线分析长图.png`
     - 设计亮点：860px 宽高清竖版信息图，包含 SVG 矢量五维能力雷达图、26 分失分根因环形图、4 道典型错题病灶切片与处方表、三周 +15 分靶向提分路线图及家长沟通摘要（明确标注为合理虚构的教学演示示例数据）。
  2. **离线互动检索工作台**
     - 源文件：`高一力学经典模型速查网页.html`（引用设计包本地 KaTeX）
     - 单文件成品：`_showcase/高一力学经典模型速查网页.html`（经 `kit/pack.cjs` 内嵌离线 KaTeX 字体与脚本，零外链）
     - 设计亮点：收录高一必修一 12 大高频力学模型（前 3 个紧扣电梯台秤、下蹲起立传感器、系统超失重），配备 SVG 受力示意图、实时关键词检索、5 大专题筛选、电梯视重速算滑块、「遮住公式自测」默写开关与母题秒解折叠卡。
  3. **可玩物理闯关小游戏**
     - 源文件与成品：`超重与失重·太空电梯闯关小游戏.html` → `_showcase/超重与失重·太空电梯闯关小游戏.html`
     - 设计亮点：原生 HTML5 Canvas 太空电梯驾驶舱，设「第 1 关·直觉破壁快判」「第 2 关·推进器精准控重」「第 3 关·900 N 过载红线软着陆实时驾驶」三大关卡，轿厢尾焰、双针台秤表盘、隔离体受力箭头同屏实时联动，含连击计分与满星通关勋章反馈。
