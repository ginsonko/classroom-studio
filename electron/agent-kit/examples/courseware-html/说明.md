# 样板：超重与失重 · 互动课件

- **主题**：高一物理「超重与失重」（人教版 2019 必修第一册 第四章，$g = 10\,\mathrm{m/s^2}$）
- **风格与版式**：`clean`（清爽白，自定义青蓝/暖橙双强调色 `#176d80` / `#c76a32`），共 10 页（封面 → 生活线索三景 → 隔离体受力图 → 牛顿第二定律分步推导 → 手绘 $a\text{–}t$ 电梯实验室 → 两步方向判断归纳表 → 减速下降原创例题 → 知识结构图与完全失重 → 3 道即点即判随堂小测 → 答案解析）。
- **核心互动**：第 5 页「电梯实验室」支持鼠标/触屏 Pointer 事件直接在 $a\text{–}t$ 图上手画任意加速度曲线，或一键切换「上行：启动→匀速→制动」「下行：启动→匀速→制动」「自由落体：完全失重」三组预设；轿厢按 $v=\int a\,\mathrm{d}t$、$x=\int v\,\mathrm{d}t$ 实时积分运动，台秤指针读数 $F_N/g$、弹簧压缩量、支持力 $F_N=m(g+a)$ 与重力 $mg$ 受力箭头同步变化。
- **文件说明**：
  - `超重与失重.html`：引用 `../../` 设计包的源文件（供 AI 工坊作样板参考，体积小）。
  - `_showcase/超重与失重.html`：经 `kit/pack.cjs` 内嵌离线 KaTeX 字体与 `cs-deck` 后的单文件成品，断网及手机竖屏均可直接打开。
